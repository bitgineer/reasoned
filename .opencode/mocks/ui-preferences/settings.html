Gradient descent

Follow the slope.

How can a local slope guide us toward a minimum?

The derivative tells us which way the function rises. Gradient descent takes a small step against it.

f(x) = x²f′(x) = 2x

The update rule repeats that step until the slope flattens.

xₙ₊₁ = xₙ − α · f′(xₙ)

At x = 3 the derivative is 6. With a learning rate of 0.1, the next x is 2.4, a step left toward zero.

Question Gradient descent · Question Read lesson Transcript

At x = 3, which direction reduces f(x) = x² for a small step?

Left, toward zero. Right, away from zero. Stay at x = 3.

Keep

Density changes the whole rhythm of a session, and small phones need it.

Font scale is the only control that helps a reader who wants larger prose without larger chrome.

Question card is the one choice a learner can feel in the first minute.

Trim

Dock content drops from three values to two, Full and Composer. The middle option saves one chip and hides the thinking level.

Question card keeps Inline card and Full screen. The bottom sheet needs the same overlay card and scrim as full screen and returns less room.

Leave out

Reading measure. At 390 dp the default already lands near 44ch and 56ch is clamped by the screen. Only Narrow changes anything, and it spends about 56 dp on gutters. The control earns a row on a tablet, not on this phone. Cap prose at 68ch and center it on wide windows instead.

Keyboard behaviour. Touch users press the button. Hardware keyboard users expect Enter to send and Shift + Enter to add a line. A picker asks a question with one good answer per device.

Ship inline as the default. Offer full screen.

Full screen is not the default because losing the passage is the most common failure in a learning question. The transcript pill makes it recoverable in one tap, but recovery is not the same as presence. Use full screen when the question text is long or the reader has raised the font scale. Cut the bottom sheet. It needs the same overlay card and scrim as full screen and returns less room.

  • Inline for the default path
  • Full screen for focus and large type
  • No sheet, no third layout to maintain
  • One answer surface per mode
